# SMS lead alert

Texts you every new lead the moment it comes in: their name, number, what they need, and a reply you can send back.

Built as a Zapier Next Gen Zap. Inspired by [this post](https://x.com/MosesD02/status/2110732643964756369).

## Use it
Paste into Claude, ChatGPT, or Cursor with Zapier MCP connected:

> Build me the Next Gen Zap described in github.com/zapier/community-skills/tree/main/skills/andrewckor/sms-lead-alert using Zapier MCP.

Coding agents can also run `npx skills add zapier/community-skills --skill sms-lead-alert`.

## Files
- `SKILL.md` tells your AI how to build and set it up
- `workflow.ts` is the working Next Gen Zap code
