# Unpaid invoice nudge

Every unpaid invoice gets a reminder before you have to ask. 3 days past due, the customer gets a friendly email in your voice with the pay link. Still unpaid on day 7, you get a text.

Built as a Zapier Next Gen Zap. Inspired by [this post](https://x.com/MakadiaHarsh/status/2111026756572639431).

## Use it
Paste into Claude, ChatGPT, or Cursor with Zapier MCP connected:

> Build me the Next Gen Zap described in github.com/zapier/community-skills/tree/main/skills/andrewckor/unpaid-invoice-nudge using Zapier MCP.

Coding agents can also run `npx skills add zapier/community-skills --skill unpaid-invoice-nudge`.

## Files
- `SKILL.md` tells your AI how to build and set it up
- `workflow.ts` is the working Next Gen Zap code
