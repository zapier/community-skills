# Google review reply draft

Every new review gets a reply drafted in your voice and emailed to you to approve. 1 and 2 stars text you right away. 5 stars land in your Testimonial Tuesday sheet.

Built as a Zapier Next Gen Zap. Inspired by [this post](https://x.com/bradsmith/status/2110767002713223658).

## Use it
Paste into Claude, ChatGPT, or Cursor with Zapier MCP connected:

> Build me the Next Gen Zap described in github.com/zapier/community-skills/tree/main/skills/andrewckor/google-review-reply-draft using Zapier MCP.

Coding agents can also run `npx skills add zapier/community-skills --skill google-review-reply-draft`.

## Files
- `SKILL.md` tells your AI how to build and set it up
- `workflow.ts` is the working Next Gen Zap code
